## 2. Secret & Credential Masking Audit

All sensitive credentials utilized by the platform were audited:
- **SNMPv3 Credentials**: Authenticated with SHA-256 and encrypted with AES-128 (`authPriv`). The authentication password and privacy passphrases are stored encrypted in Zabbix host macros (`{$SNMP_SECRETS}`) and masked in all external logs.
- **Zabbix API Credentials**: Session tokens are used instead of permanent hardcoded credentials in automation jobs.
- **Zero Inbound Platform Leaks**: External notifications generated by Zabbix omit raw SQL strings, stack traces, and internal database passwords.
- **Zero Platform Branding**: Notification messages sent to administrators and the IT Service Desk strictly omit internal tool names ("Nawari", "Zabbix", "Grafana").
